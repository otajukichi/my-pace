# 英会話の教材・記録・接続

MyPaceで練習を選び、ChatGPTで話し、MyPaceに取り組んだ記録を残す構成です。会話本文や音声はMyPaceへ保存しません。英語力の判定もしません。

## 現在できること

- 8つの会話エリア、詳細テーマ、3つの練習形態、独立した音読の選択。
- 教材のカタログJSONとDriveフォルダ参照を、このブラウザに設定。
- 教材本文を含めず、参照情報と練習形態だけの開始用テキストをコピー。
- 練習後に本人が記録し、この端末で履歴と経験したテーマを確認。
- 記録受付の入力検証・重複防止・MCP形式を、外部通信しないテストで確認。

**Driveへの履歴保存、端末間同期、ChatGPTからの自動記録はまだ未接続です。** 画面の手動記録はこのブラウザ内の保存であり、GoogleにログインしてもDrive同期にはなりません。ブラウザの保存データを消すと失われます。「教材・保存」→「バックアップ」で履歴を書き出し、「読み戻す」で重複を避けて取り込めます。バックアップに教材カタログ・フォルダIDは含まれないため、別端末では教材設定を別途行います。

MyPace側に有料APIや常駐PCは必要ありません。ChatGPTのDrive連携・音声・カスタム連携が使えるかは利用アカウントと端末で別途確認します。今回、その利用権を保証したり、有料プランを必須にしたりはしていません。

## 教材の置き場所

本人が管理する非公開フォルダに、次の形で置きます。`running` のフォルダや認証設定は変更しません。

```text
my-pace/
├── running/                       既存のまま
└── english/
    ├── materials/
    │   ├── catalog.json           タイトル・説明・参照情報だけ
    │   └── people-first-meeting.md ChatGPTが読む教材本文
    └── history/                   将来の履歴保存先。今は作成不要
```

`materials` が開始用テキストに入る教材フォルダです。フォルダIDや教材ファイルIDはアクセス権を与える秘密鍵ではありませんが、個人の参照先なので公開ソースへ書き込みません。

### 最初の教材を1件用意する

1. [教材例](materials/example.md)を `people-first-meeting.md` という名前で、自分のDriveの `english/materials` に置きます。本文の教材IDは維持します。
2. [カタログ例](catalog.example.json)をコピーして `catalog.json` とし、その教材の項目に `"fileId": "実際の教材ファイルID"` を追加します。ファイルIDはDriveのファイルリンクに含まれます。
3. `catalog.json` も同じ `materials` に置きます。MyPaceの英会話ページで「教材・保存」を開き、「英会話教材フォルダのURL または ID」に `materials` の参照先を入力して「フォルダを保存」します。「目次JSONを読み込む」から `catalog.json` を選びます。
4. 自分のChatGPTでGoogle Driveの読込を準備します。これはMyPace右上のGoogleログインとは別の接続です。ChatGPT側に表示される権限を確認し、この練習のためにDrive全体への書き込み権限は追加しません。使える接続がその権限を必須にしている場合は、今回の条件に合う教材読込の接続方法が別途必要です。

現在のカタログ取り込みはファイルの手動読み込みです。Drive上の `catalog.json` を変更しただけではMyPaceの一覧は更新されません。変更後にそのJSONを再度取り込んでください。教材本文はMyPaceへ取り込みません。

`fileId` は省略可能ですが、実際の接続では指定を推奨します。省略時は指定フォルダの `catalog.json` で教材IDを確認し、同じフォルダの `{教材ID}.md` を参照する規約です。例は `people-first-meeting.md`。この規約に合わないファイル名やGoogleドキュメントを使う場合は `fileId` を指定します。教材が見つからない場合に内容を代作してはいけません。

### カタログの形式

```json
{
  "schema": 1,
  "materials": [
    {
      "id": "people-first-meeting",
      "kind": "conversation",
      "areaId": "people",
      "title": "はじめての会話",
      "description": "初めて会う人と、お互いのことを少しずつ話す。",
      "durationMinutes": 5
    }
  ]
}
```

| 項目 | 値 |
| --- | --- |
| `id` | 変更しない教材ID。英小文字で始まり、英小文字・数字・ハイフン、80文字以内。重複不可 |
| `kind` | `conversation` または `reading` |
| `areaId` | 会話は下表のID。音読は `null` |
| `title` / `description` | タイトル80文字以内、短い説明200文字以内。ネタバレや本文を入れない |
| `durationMinutes` | 目安の整数、1〜60分 |
| `format` | 音読だけ任意指定。`phrases` / `dialogue` / `speech` / `article` / `research` |
| `fileId` | 任意のDrive教材ファイルID。英数字・`_`・`-`、10〜200文字 |

| エリア | ID | エリア | ID |
| --- | --- | --- | --- |
| 初対面・人間関係 | `people` | 旅行・移動 | `travel` |
| 日常・近況 | `daily` | 意見・議論 | `ideas` |
| 趣味・文化 | `culture` | 問題・相談 | `problems` |
| 暮らし・サービス | `services` | 仕事・研究 | `work` |

教材は最大5,000件、カタログはJSON文字列で最大300万文字、画面から選ぶファイルは6MB以内です。教材本文・登場人物の設定・指示文は別ファイルへ置きます。未知の項目や不正なIDを含むJSONは取り込みません。テーマ追加のためのアプリコード変更は不要です。最初に表示される29件（会話24件・音読5件）はテーマ一覧の見本であり、教材本文がDriveに配置済みという意味ではありません。

練習形態と解放条件は `lib/english-model.js` の設定データに分離しています。上位形態が使えるようになっても下位形態は残ります。解放は経験の蓄積による選択肢の追加で、英語力の認定ではありません。音読に解放制限はありません。

## スマホで最初の1件を確認する

大容量CSVやGASの検証をやり直す必要はありません。教材1件と短い会話で、次の順に確認します。

1. MyPaceの「会話」でエリア・設定済み教材・「シーン会話」を選び、「このテーマで話す」→「開始文をコピー」を押します。音読なら「音読」→教材→「この文章を音読する」です。
2. スマホのChatGPTの**テキスト会話**に貼り付けます。接続済みGoogle Driveから指定教材を取得し、本文を見せずに準備できたことだけを返すか確認します。
3. 読み込めたことを確認してから、同じ会話で音声モードを開始します。教材の場面・練習形態が引き継がれるか、短いやり取りで確認します。
4. 終了後にMyPaceへ戻り、「準備した練習に戻る」→「練習を記録」→「練習を終えたので記録する」を押します。「足あと」で履歴を確認します。再読み込みしても履歴が残り、同じセッションを二重記録しないことを確認します。コピーしただけで実施済みにはなりません。

教材が見つからない場合は、Google Driveの接続アカウント、フォルダID、`catalog.json`、教材の `fileId` を順に確認します。取得できないまま「準備できた」と返る場合は接続成功と扱いません。

**「テキストで読める」「同じ会話を音声へ引き継げる」「音声中に専用連携を呼べる」は別の確認です。** 3つ目は下記の記録連携が実装されてから確認します。音声中のツール呼び出しが使えなければ、テキストでの記録依頼や手動記録を使います。

### ChatGPT側の対応状況

2026-11-20に確認した公式文書では、[カスタムMCPの接続](https://developers.openai.com/api/docs/guides/custom-mcp-server)と[接続例](https://developers.openai.com/plugins/quickstart)はWebでの手順を説明しています。[スマホの使い方](https://developers.openai.com/training/walkthroughs/working-on-your-phone)には接続済みプラグインの利用がありますが、今回必要な「スマホで教材準備後、そのまま音声練習と自動記録」の組み合わせまで動作保証する記述は確認できませんでした。

[Voiceの文書](https://learn.chatgpt.com/docs/features/voice)はデスクトップの対応プランやRemoteについての案内です。これをスマホ単独・無料アカウントでの動作保証に読み替えません。使える機能はアカウント・端末側で確認し、MyPaceのためにPC常駐や有料契約を追加する前提にはしません。

## 記録の自動連携：実装済みの境界と残り

`server/english-service.js` は、英会話専用の認証・保存アダプターを差し込む受付ロジックです。既存のランニング用OAuthやDrive読込処理からは独立しています。

公開エンドポイント `/api/english` は、現時点では `configured: false` を返し、書き込みは `ENGLISH_UNCONFIGURED`（503）で拒否します。環境変数や固定トークンを追加するだけで有効になる仕組みはありません。MCPの初期化・ツール一覧・実行はテスト用アダプターで検証しており、接続済みサービスとしては公開していません。

受け付ける記録は次の形式です。会話本文、音声、任意の保存先は受け取りません。

```json
{
  "schema": 1,
  "sessionId": "00000000-0000-4000-8000-000000000001",
  "performedAt": "2026-11-20T00:00:00.000Z",
  "kind": "conversation",
  "areaId": "people",
  "themeId": "people-first-meeting",
  "modeId": "scene"
}
```

上のセッションIDは形式の例です。実際は練習ごとに新しいIDを生成し、同じ練習の再送には同じIDを使います。音読は `kind: "reading"`、`areaId: null`、`modeId: "reading"`。この記録は取り組んだ事実を示し、能力や教材の達成率を表しません。

自動保存を有効にするには、次の実装が必要です。**現段階で利用者にOAuth設定の変更や新しいシークレット登録を求めるものではありません。**

1. ChatGPT向けOAuthの認証・トークン検証。本人・発行元・宛先・期限を確認し、`english:practice:append` の記録追加専用権限を確認する。
2. サーバー設定だけで保存先を `english/history` に固定するDrive保存アダプター。本人所有・非共有・親子関係を検査し、同一セッションの同時送信でも一件だけ作成する。
3. 本人認証付きの英会話履歴読み込みと、端末内の手動記録との重複しない統合。
4. 認証付きMCPとして接続し、`record_practice` 一つだけを公開する。読み出し・更新・削除・自由なファイル指定は公開しない。

DriveのフォルダIDを指定することと、Google側のOAuth権限をフォルダ単位に絞ることは同じではありません。権限の選定とコードの保存先制限の両方を接続実装時に扱います。教材読込に使うChatGPTのGoogle Drive接続も、別途その接続が持つ権限に従います。

完成後の最小確認は、認証済み本人から一件保存 → 同じセッションを再送して件数が増えない → 未認証の送信を拒否 → MyPaceで一件表示、です。その後に同じ記録操作をスマホの音声から行えるか確認します。既存ランニングの再検証は不要です。

## 開発時の確認

```bash
node --test tests/english-model.test.mjs tests/english-service.test.mjs
npm test
npm run build:public
```

英会話のテストはモックのみで、Google Driveへ書き込みません。実ID・個人教材・練習履歴をソース、公開ビルド、スクリーンショットへ含めないでください。
