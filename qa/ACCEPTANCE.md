# 手元でのブラウザー確認

このリストは実ブラウザーQAが実行できる環境で使用します。自動テストの成功は、見た目・ブラウザー操作の検証済みを意味しません。

## 準備

1. `npm run verify`、`npm start` を実行。
2. 新しいブラウザープロファイルで http://localhost:5173 を開く。
3. PC幅（1440 / 1024）とスマートフォン幅（390 / 320）で以下を確認。
4. 通信エラー、コンソールの例外、横にはみ出す画面、ボタンの重なりがないことを確認。

## 早起き

- [ ] 何も記録されていない状態から開始する。
- [ ] 「今起きた」が現在時刻だけを保存する。連打で複数記録にならない。
- [ ] 時刻を00:00に編集して保存できる。
- [ ] 過去の日の時刻を入力する。今日の記録は上書きされない。
- [ ] 7日 / 30日を切り替える。未記録日に点がなく、線も欠ける。
- [ ] 起床の目安を設定・解除できる。入力欄は毎日の時刻と別になっている。
- [ ] キャンセル、Esc、別ページへの移動で未保存の変更が入らない。
- [ ] 履歴から編集・削除し、削除直後に元へ戻せる。

## ランニング

- [ ] 距離5km・30分でペース6:00/kmが表示される。
- [ ] 同日の別ランを保存して2件残る。
- [ ] 0分0秒や空欄の距離は拒否される。
- [ ] 日付やメモを編集し、元へ戻せる。
- [ ] GPXを選ぶと保存前プレビューが出る。キャンセルで記録が増えない。
- [ ] トラック区間の切れたGPXが直線で結ばれない。
- [ ] タイムスタンプなしのGPXは手入力の時間が必要になる。
- [ ] 壊れたGPXや巨大ファイルで既存記録が変わらない。
- [ ] メモに `<script>alert(1)</script>` を入力しても文字として見える。

## 習慣

- [ ] チェック、数値（水・杯）、時間（読書・分）を作成する。
- [ ] 今日と過去の日で個別に記録する。
- [ ] 数値0を保存でき、未記録と区別される。
- [ ] 目安達成でチェック表示に変わる。名前・単位・目安を編集する。
- [ ] お休み・再開で過去の記録が消えない。
- [ ] 長い日本語の名前でもボタンが押せ、横にあふれない。

## 保存・復元・中断

- [ ] 再読み込み後もすべての記録が残る。
- [ ] JSONダウンロードを行い、復元後に同じ記録になる。
- [ ] 復元のキャンセルが既存データを変えない。
- [ ] 復元後、元に戻すで前のデータに戻る。
- [ ] 不正JSON・異常な数値・重複IDの復元を拒否する。
- [ ] 同じブラウザーで2タブを開く。片方で保存するともう片方の編集中ダイアログが閉じ、最新状態に更新される。
- [ ] Back / Forward によりページが切り替わる。
- [ ] キーボードだけでタブ、ボタン、フォームへ移動でき、フォーカスが見える。
- [ ] 保存不可・容量超過では保存成功メッセージが出ず、直前の保存済み状態を維持する。

Google Drive / Google ログイン / LINE は未実装です。接続・同期・通知を試験する段階ではありません。

## 中断の追加チェック

- [ ] 大きなGPXの読み込み中に別のラン入力を開いても、遅い読み込み完了が新しい入力内容を上書きしない。
- [ ] 元の保存データが壊れている場合、復元前に退避・取り消し不可を案内し、復元後に空状態へ戻すUndoを出さない。


## サイドバーの追加確認（実ブラウザーでは未実施）

- [ ] PC幅で閉じると左にアイコン列も残らず本文が広がり、再読み込み後も閉じた状態。開くボタンから戻せる。
- [ ] 600px以下では最初は閉じており、下部に空白のナビ領域が残らない。320 / 390 / 600 / 601 / 850 / 1440pxで確認。
- [ ] モバイルは背景・閉じる・Esc・現在ページを含むページ選択で閉じ、開くボタンまたは移動先本文へフォーカスが戻る。
- [ ] モバイルの開いたメニューではTab / Shift-Tabが内部を巡回し、背景は操作・スクロールできない。
- [ ] 記録ダイアログの入力中はEscがダイアログに作用し、幅変更で入力値が消えない。
- [ ] メニュー開閉の連打、幅変更、戻る / 進む、別タブ更新後も背景操作が戻り、フォーカスが消えない。
- [ ] PCの「内容へ移動」リンク、開閉ボタンの読み上げ、アプリ名の改行・重なりを確認。
