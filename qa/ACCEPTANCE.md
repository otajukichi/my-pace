`npm run verify`、`npm start`。必ずこれまでと同じ http://127.0.0.1:5173 を開きます。

- [ ] 幅419 / 420px、759 / 760pxの境界でも全アイコンが見え、44px以上のタッチ領域が確保される
- [ ] 通常サイズで文書の縦横スクロールがなく、各画面が収まる
- [ ] ウィンドウを連続リサイズしても項目・ボタンが消えない
- [ ] 低い横向き画面（844×390）、200%/400%拡大では必要な枠内スクロールで全操作へ到達できる
- [ ] スマートフォンのキーボード表示中も保存・キャンセルが枠内で到達可能
- [ ] コントラスト、読みやすさ、長い日本語名、最大数値でも重なりがない
- [ ] コンソールに例外やCSP違反がない

- [ ] アプリ名「マイペース」が折り返さない

## ホーム・早起き・ランニング・習慣

- [ ] 空の状態に作られた実績がない。ホームに選んだ日の実際の記録が表示される

- [ ] 過去日・目安・7日/30日切替が動く。未記録日には点を描かない
- [ ] ラン5km/30分が6:00/km。同日に複数ランを記録できる
- [ ] ランの全文メモ・GPXルートを履歴→編集で確認できる
- [ ] 0時間、壊れたGPX、巨大GPXは拒否。古い非同期読込が新しい編集を上書きしない

- [ ] 30件を超える起床・ラン、20個以上の習慣も最後までページ送りできる
- [ ] 最終ページで削除・復元しても空の行き止まりページに留まらない

## カレンダーと日記

- [ ] 月送り、ヘッダーの日送り、今日に戻るで月と選択日が整合する
- [ ] 1900年1月・2200年12月の境界で範囲外へ移動しない

- [ ] 日記の本文・任意の気分・気分だけの記録を保存
- [ ] 8,000文字の日本語・絵文字・改行を含む日記がページ送りで末尾まで読める

## 暮らしの庭

- [ ] 未記録時には未成長の庭。過去の本物の記録があると相応に育っている
- [ ] 同じ日の起床・複数ラン・習慣・連打でも1日分だけ増える
- [ ] 未来の記録、0/falseの習慣、予定・日記だけでは増えない
- [ ] 休んだ日が挟まっても減らない。元の記録を全て削除するとその日分が減り、Undoで戻る
- [ ] 7日/21日で花が解放。花・昼夕夜の選択が再読込後も残る
- [ ] 解放条件を下回っても好みは残り、条件を再度満たすと元の花に戻る
- [ ] 「育つしくみ」の内容を小さい画面でもページ送りで読める

## 保存・復元・失敗

- [ ] 旧version1 JSONを読み込み、起床・ラン・習慣がそのまま残る
- [ ] 読込だけでは元のlocalStorageを書き換えず、最初の保存でversion2になる
- [ ] version2 JSONで予定・日記・庭まで往復復元できる
- [ ] 復元前の確認に予定・日記の件数も表示。キャンセルは無変更
- [ ] 異常値・未知フィールド・重複ID・UTF-8で12MiB超を拒否
- [ ] 壊れた既存データは保持し、変更停止・原本退避を案内
- [ ] 容量超過で成功扱いせず、編集画面と前の保存状態が残る
- [ ] 別タブ更新で古い編集を閉じ、最新を読み込む（未保存下書きは残らない）
- [ ] コード復元は記録のversionを戻さない。旧版が必要なら旧version1 JSONで復元
