MY PACE / PRIVACY

記録とデータの取り扱い。

更新日：2026年10月7日 · 個人利用の試作版

このページは、個人用試作アプリ「マイペース（My Pace）」が取り扱うデータ、保存先と利用目的を説明します。

取り扱うデータと目的

  • 起床時刻、習慣と達成状況、ランニング、予定、日記・メモ、気分、アプリの設定を、記録・表示・集計・同期のために使用します。
  • 取り込む CSV・GPX に含まれる日時、距離、位置情報・GPS ルート、標高やセンサー値などを、ランニングの表示と振り返りに使用します。取り込み元によって含まれる項目は異なります。
  • Google ログインでは ID トークンをサーバーで検証し、確認済みメールアドレスと Google のアカウント識別子（sub）などを本人確認に使用します。クラウドへのアクセスは設定された所有者に限定します。

保存先と処理の流れ

クラウド未接続の記録は、ブラウザーの localStorage に保存します。クラウド利用時は、Google Drive の固定した個人用保存先を永続的な保存先とし、IndexedDB に記録のキャッシュと未送信の変更を保存します。古いブラウザー内の記録は、クラウドへの移行後も自動では削除しません。

ログイン・同期の要求は Vercel 上のサーバーで処理し、署名付きの要求を Google Apps Script に送り、所有者の Drive を読み書きします。アプリの画面配信、認証、保存・同期のために Vercel と Google の基盤を利用します。これらの提供者による通信情報・運用ログ等の処理には、それぞれのポリシーも適用されます。

Google Drive のアクセストークンやサーバーの共有秘密をブラウザーへ渡す設計ではありません。ログイン状態には有効期限のあるセッション Cookie を使います。端末内のデータは、アプリ独自の暗号化やプライバシーロックで保護されるものではありません。

Google Drive の権限と実際の利用範囲

Apps Script に設定する drive.readonly は、権限としては Drive 全体のファイルの閲覧・ダウンロードを許可します。特定のフォルダーだけに限定された OAuth 権限ではありません。このアプリのコードは、指定した running_data フォルダーの CSV と、管理する保存先・その配置確認に必要な情報を処理対象とします。

drive.file は、アプリが作成したファイルや利用を許可されたファイルの作成・更新などに使う権限です。記録の書き込みは固定されたアプリ管理用の保存先に行い、取り込み元の CSV は変更しません。詳細は Google の Drive API 権限の説明 を参照してください。

利用・共有の範囲

記録と Google から取得したユーザーデータは、本人確認と、このアプリの記録・表示・同期機能のために使用します。データを販売したり、広告の配信や広告目的の第三者提供に使ったりしません。アプリのコードに広告やアクセス解析の仕組みは組み込んでいません。これは、基盤提供者が一切の情報を処理しないという意味ではありません。

Google API から取得した情報の使用および他のアプリへの転送は、Limited Use（用途制限）の要件を含む Google API Services User Data Policy に従う方針です。この記載は Google による審査・承認を示すものではありません。

保存期間・削除・接続解除

ブラウザー内のデータと Drive 内のデータは別に保存され、一定期間後にすべて自動削除する機能はありません。ログアウトはクラウドの表示とセッションを閉じる操作です。キャッシュや未送信の変更、Drive 上の記録を削除する操作ではありません。

  • 端末内のデータを消す場合は、必要な記録を退避し、未送信の変更がないことを確認してから、ブラウザーの設定でこのサイトのデータを削除します。未送信の変更を消すと復元できないことがあります。
  • Drive のデータを整理・削除する場合は、同期や定期取り込みを停止し、必要なバックアップを確認したうえで、所有者が Drive 側で対象を確認して操作します。ブラウザーのデータ削除だけでは Drive の記録は消えず、Drive の削除だけでも端末内のコピーは消えません。保存先・履歴・設定ファイルの一部削除は同期を壊すことがあります。
  • Google 側の接続・権限は Google アカウントの接続管理 で確認できます。接続解除は、既に保存されたデータの削除を意味しません。Apps Script の定期トリガーは別途停止が必要です。
